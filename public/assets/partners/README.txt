Hiring-partner logos for the "Companies Working With Us" strip on the home page.

Drop logo files here, then list them in src/data/partners.ts:

    { name: "Acme Corp", url: "/assets/partners/acme.png" }

Format: SVG or transparent PNG, roughly 200x80. The marquee shows every logo
in greyscale and brings it to full colour on hover, so dark artwork reads best.

Only real hiring partners belong here — the strip tells visitors these
companies work with RecruitKr.
